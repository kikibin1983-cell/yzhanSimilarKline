# A股K线智能分析系统 - 便携版分发指南

## 包含文件
1. `streamlit_app.py` - 主应用文件
2. `tdx_reader.py` - TDX数据读取器
3. `安装器.bat` - 一键安装脚本
4. `启动.bat` - 启动脚本
5. `用户手册.md` - 使用说明
6. `weekly_cache/` - 周线数据缓存
7. `monthly_cache/` - 月线数据缓存
8. `search_cache/` - 搜索缓存

## 使用方法

### 第一步：安装（只需一次）
1. 双击 `安装器.bat`
2. 脚本会自动：
   - 下载便携版Python（如果未安装）
   - 安装所有依赖包
   - 创建虚拟环境
   - 生成启动脚本

### 第二步：运行（每次使用）
1. 双击 `启动.bat`
2. 等待浏览器打开（或访问 http://localhost:8501）

## 系统要求
- Windows 10/11 64位
- 2GB+ 可用内存
- 1GB+ 可用硬盘空间
- 网络连接（用于下载数据和依赖）

## 文件结构（安装后）
```
yzhanSimilarKline/
├── streamlit_app.py      # 主应用
├── tdx_reader.py         # 数据读取器
├── 安装器.bat            # 安装脚本
├── 启动.bat              # 启动脚本
├── venv/                 # Python虚拟环境
├── python-portable/      # 便携版Python（可选）
├── weekly_cache/         # 数据缓存
├── monthly_cache/        # 数据缓存
└── search_cache/         # 搜索缓存
```

## 注意事项
1. **首次安装**需要网络连接下载依赖包
2. **首次运行**需要下载金融数据，请耐心等待
3. 防火墙可能会提示，请允许访问端口8501
4. 如果安装失败，请检查网络连接
