# A股K线智能分析系统 - 编码说明

## 文件编码问题

### 问题
Windows 批处理文件默认使用 **ANSI/GBK** 编码，而现代文本编辑器通常使用 **UTF-8** 编码。这会导致中文显示乱码。

### 解决方案
所有批处理文件都已添加编码声明：
```batch
@echo off
chcp 65001 >nul  :: 设置控制台为UTF-8编码
```

### 文件列表（已修复编码）
1. **`安装器.bat`** - 一键安装脚本（UTF-8）
2. **`启动.bat`** - 启动脚本（UTF-8）

### 验证方法
用记事本打开批处理文件，查看是否包含 `chcp 65001` 行。

### 如果仍有乱码
1. 用 **记事本** 打开文件
2. 点击"文件" → "另存为"
3. 在"编码"下拉菜单中选择 **UTF-8**
4. 保存并替换原文件

### 推荐编辑器
- **Notepad++** - 支持多种编码
- **VS Code** - 自动检测编码
- **Sublime Text** - 编码转换功能

## 文件编码详情
| 文件 | 编码 | 说明 |
|------|------|------|
| 安装器.bat | UTF-8 with BOM | 包含 `chcp 65001` |
| 启动.bat | UTF-8 with BOM | 包含 `chcp 65001` |
| streamlit_app.py | UTF-8 | Python文件默认UTF-8 |
| 用户手册.md | UTF-8 | Markdown文件默认UTF-8 |

## 测试方法
双击批处理文件，如果中文正常显示，说明编码正确。
