# A股K线智能分析系统 - 便携分发版

## 📦 包含内容

本分发版包含以下文件：

### 核心文件
- `streamlit_app.py` - 主应用程序
- `tdx_reader.py` - TDX数据读取器
- `requirements.txt` - 依赖包列表

### 安装与启动
- `安装器.bat` - **一键安装器** (双击运行)
- `启动.bat` - 应用启动器 (安装后使用)

### 配置文件
- `.env` - 环境变量配置
- `.env.template` - 环境变量模板

### 用户文档
- `README.md` - 项目详细说明
- `用户手册.md` - 用户使用手册
- `README_便携版.md` - 便携版使用说明
- `编码说明.md` - 编码问题解决方案

### 数据目录 (空)
- `securities_cache/` - 证券数据缓存
- `search_cache/` - 搜索缓存  
- `weekly_cache/` - 周线数据缓存
- `monthly_cache/` - 月线数据缓存

## 🚀 快速开始

### 方法一：一键安装 (推荐)
1. **下载本ZIP包并解压**到任意目录
2. **双击 `安装器.bat`** 运行安装程序
3. 按照提示完成安装 (自动下载Python和依赖包)
4. **双击 `启动.bat`** 运行应用
5. 访问 **http://localhost:8501** 使用系统

### 方法二：手动安装 (高级用户)
1. 确保已安装 **Python 3.11+**
2. 打开命令提示符，进入解压目录
3. 运行: `python -m venv venv`
4. 运行: `venv\Scripts\pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
5. 运行: `venv\Scripts\python -m streamlit run streamlit_app.py`

## 🔧 功能特点

### 核心功能
- ✅ **智能K线分析** - 基于历史相似度的形态识别
- ✅ **趋势预测** - 未来7个交易日的涨跌预测
- ✅ **风险分析** - 持仓期收益率和胜率统计
- ✅ **智能问答** - 基于市场数据的AI分析
- ✅ **多周期显示** - 日线/周线/月线切换

### 便携特性
- ✅ **无需Python环境** - 自动下载便携版Python
- ✅ **中文编码支持** - 完美显示中文界面
- ✅ **一键安装** - 双击即可完成所有配置
- ✅ **离线缓存** - 数据本地缓存，减少网络请求

## 📊 使用流程

1. **首次运行**
   - 运行`安装器.bat`完成环境配置
   - 运行`启动.bat`启动应用
   - 等待数据加载完成 (首次较慢)

2. **日常使用**
   - 直接运行`启动.bat`即可
   - 数据已缓存，启动速度更快

3. **数据更新**
   - 系统自动更新最新市场数据
   - 缓存数据保留30天

## 🛠️ 常见问题

### Q1: 安装器运行时显示乱码？
A: 这是Windows控制台编码问题，不影响功能。如需正确显示中文，请参考`编码说明.md`。

### Q2: 安装过程很慢？
A: 首次安装需要下载Python和所有依赖包，请耐心等待。使用国内镜像加速。

### Q3: 防火墙提示？
A: Streamlit需要访问网络获取数据，请允许防火墙访问。

### Q4: 如何更改TDX数据源路径？
A: 在应用侧边栏的"TDX数据源配置"中设置。

### Q5: 如何备份数据？
A: 备份`securities_cache/`, `search_cache/`, `weekly_cache/`, `monthly_cache/`目录即可。
