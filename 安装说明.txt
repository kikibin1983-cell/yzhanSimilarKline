# A股K线智能分析系统 - 一键安装脚本

## 解决方案

创建一个文件 `O:\WXJS\yzhanSimilarKline\一键安装.bat`，内容如下：

```bat
@echo off
echo ========================================
echo   一键安装所有依赖 (解决所有模块缺失)
echo ========================================
echo.

cd /d "%~dp0"

echo 检查Python...
python --version
if errorlevel 1 (
    echo [错误] 未找到Python，请先安装Python
    pause
    exit /b 1
)

echo.
echo [开始] 一次性安装所有依赖...
echo 这可能需要5-10分钟，请耐心等待...
echo.

echo 步骤1: 升级pip...
python -m pip install --upgrade pip -i https://pypi.tuna.tsinghua.edu.cn/simple

echo.
echo 步骤2: 安装requirements.txt中的所有依赖...
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

echo.
echo 步骤3: 安装额外的必需依赖...
python -m pip install python-dotenv altair pyarrow toml watchdog pygments click rich packaging -i https://pypi.tuna.tsinghua.edu.cn/simple

echo.
echo ========================================
echo   验证所有模块
echo ========================================
echo.

python -c "import streamlit; print('OK: streamlit')"
python -c "import pandas; print('OK: pandas')"
python -c "import numpy; print('OK: numpy')"
python -c "import plotly; print('OK: plotly')"
python -c "import scipy; print('OK: scipy')"
python -c "import sklearn; print('OK: sklearn')"
python -c "import jieba; print('OK: jieba')"
python -c "import akshare; print('OK: akshare')"
python -c "import requests; print('OK: requests')"

echo.
echo ========================================
echo   安装完成！
echo ========================================
echo.
echo 现在运行程序:
echo   python streamlit_app.py
echo.
pause
```

## 最简单的方法 - 复制下面内容

将以下内容复制并保存为 `O:\WXJS\yzhanSimilarKline\一键安装.bat`：

```
@echo off
cd /d "%~dp0"
python -m pip install --upgrade pip -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip install python-dotenv altair pyarrow toml watchdog pygments click rich packaging -i https://pypi.tuna.tsinghua.edu.cn/simple
python -c "import streamlit, pandas, numpy, plotly, scipy, sklearn, jieba, akshare, requests; print('ALL OK!')"
echo Done! Run: python streamlit_app.py
pause
```

## 使用方法

1. 复制上面的内容
2. 保存为 `O:\WXJS\yzhanSimilarKline\一键安装.bat`
3. 双击运行
4. 等待5-10分钟安装完成
5. 运行 `python streamlit_app.py`

安装完成后运行：

```cmd
python -c "import streamlit, pandas, numpy, plotly, scipy, sklearn, jieba, akshare, requests; print('ALL MODULES OK!')"
```

如果显示 "ALL MODULES OK!"，说明所有模块都安装成功了。
