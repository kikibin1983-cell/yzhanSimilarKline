Stock K-Line Analysis System
========================================

INSTALLATION STEPS:
1. Double-click "安装程序.bat" (Install.bat)
2. Wait for installation (5-10 minutes first time)
3. After installation, double-click "Qidong.bat" to start

HOW TO USE:
1. Double-click "Qidong.bat"
2. Browser will open automatically
3. Default address: http://localhost:8501

SYSTEM REQUIREMENTS:
- OS: Windows 10/11 (64-bit)
- RAM: 8GB+ recommended
- Disk: 500MB+ free space
- Network: Required for stock data
