# 青岚方块

本机浏览器中的单机创造沙盒。探索方块山地、树林、水岸和洞穴，挖掘并自由建造，再保存自己的世界。

## 开始玩

1. 双击本目录的 **启动游戏.bat**。它会自动打开 `http://127.0.0.1:8765`。
2. 点击“创建新世界”，输入种子（或保留默认值），点击“创建并进入”。
3. 保持启动窗口运行；关闭窗口会停止本地服务。游戏中 Esc 暂停并释放鼠标。
4. 下次启动，使用同一个浏览器、同一个地址，点击“继续我的世界”。

当前机器已具备 Node.js。移动到其他电脑时需要 Node.js 20 以上和支持 WebGL2 的桌面浏览器；无需安装游戏依赖、Python 或游戏引擎。资源已包含在 `vendor/`，正常游玩不需要互联网。

若浏览器没有自动打开，可手动访问上述地址。终端启动命令：

```powershell
node server.mjs --open
```

8765 被另一个青岚方块服务占用时，会打开已有服务。被其他程序占用时会提示并退出，不会结束其他程序。可用 `node server.mjs --port=8766 --open` 更换端口，但不同端口有不同的浏览器存档空间，需要导出再导入迁移。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 观察 | WASD / 鼠标 |
| 跳跃、水中上浮 | 空格 |
| 冲刺 | Shift |
| 挖掘 / 放置 | 左键 / 右键，可按住连续操作 |
| 切换方块 | 1–9 或滚轮 |
| 方块选择 | E；点击方块替换当前快捷栏槽位 |
| 飞行 | F；空格上升，Ctrl 下降 |
| 信息面板 | F3 |
| 暂停、保存、设置、备份 | Esc |

最大交互距离 6 格，放置不能覆盖身体。飞行也有碰撞。水不流动，底部基岩不可破坏。画面不流畅时到设置降低视距和画质。

## 存档和备份

- 一个当前世界，浏览器 IndexedDB 本地保存，游戏每 5 秒尝试自动保存。暂停后可“立即保存”，等待“已保存”再关闭。
- **导出备份**会下载 JSON，包含世界种子、建筑修改、玩家、快捷栏和设置。导入会先校验并要求确认，再替换当前世界。
- 新建世界也会替换当前存档。想保留多个世界，请先各自导出文件。
- 清理站点数据、隐私模式、换浏览器/地址/端口可能失去本地存档。导出的文件可以恢复。
- 同一来源只有一个标签页能写存档；其他标签页可玩和导出，但不能覆盖。关闭其他标签页后刷新可重新获得写入权限。
- 存储失败时建筑仍在内存中，可导出备份；损坏的存档不会在启动时被自动覆盖。
- 导入文件上限 20 MiB。只支持本项目 v1 格式，不读取《我的世界》地图。

## 首版范围

512×512 格、96 格高的有限世界；种子地形、树木、洞穴、少量矿石；11 种可选建造方块；创造模式。包含自动存档、导入导出和视距/画质/灵敏度/音量设置。

生存、合成、怪物、红石、多人和无限世界尚未实现。本项目参考方块沙盒操作方式，使用独立实现和自制纹理，不是原作完整复刻。

## 学习和验证

从 [LEARNING.md](LEARNING.md) 开始。验证记录见 [VALIDATION.md](VALIDATION.md)。

```powershell
npm.cmd test
```

测试使用 Node 内置运行器，不需要额外依赖。修改渲染库版本时才需要 `npm.cmd ci --ignore-scripts`，然后 `npm.cmd run vendor`。固定的 Three.js 版本为 0.180.0，MIT 授权文本在 `vendor/THREE-LICENSE.txt`。

可选的真实浏览器检查脚本位于 `scripts/browser-*.cjs`，需要已有 Playwright 安装和 Microsoft Edge，不属于运行游戏的依赖。结果输出到 `output/playwright/`。
