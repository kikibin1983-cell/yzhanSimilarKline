# 首版验证记录

开发开始：2026-10-04；最终验证：2026-10-05。

## 已完成验证

- Node.js v24.13.0；Three.js 固定 0.180.0，本地 vendor 含 MIT 授权。
- `npm.cmd test`：34 项全部通过，覆盖世界生成/编辑/网格、碰撞/射线、干燥出生与水中恢复、存档校验/队列、本地 HTTP 服务和占用端口识别。
- 所有自写 `src/*.js`、`server.mjs` 和浏览器脚本通过 `node --check`。
- 已用本机 Microsoft Edge / Playwright 在 1280×720 驱动真实页面，验证首页、WebGL、鼠标锁定、WASD、飞行、左键挖掘、右键放置、E 方块选择、Esc 暂停、保存、导出、刷新恢复、导入、无效文件不覆盖以及加载后的离线游玩。
- 核心浏览器流程没有 pageerror，没有外部资源请求。中档 49 个网格区块，稳态采样约 60 FPS。
- 已验证另一个标签页不能写同一存档、存储写入失败保留内存修改且可恢复、损坏存档启动/自动保存/取消新建均不会覆盖，以及确认新建后的恢复。
- 远距离跳转四处，低档每处完成加载后均为 25 个网格区块；体素缓存为 45–48 个区块，受视距约束；每处队列均归零。
- 导入写入故意延迟时，普通保存被阻止，重复新建/导入被拒绝，最终持久存档保持导入世界。
- 图形设备读取为 ANGLE / NVIDIA GeForce RTX 4060 Laptop GPU / Direct3D11；这是本机结果，不保证其他设备的帧率。
- 原股票系统 `venv\Scripts\python.exe -m unittest discover -s tests -v`：49 项通过（43.538 秒）。游戏未修改股票系统源码、Python 依赖或用户数据。

## 检查脚本和证据

`scripts/browser-smoke.cjs` 是真实操作流程，`scripts/browser-edge.cjs` 检查存储异常和区块缓存；它们使用已有 Playwright + Edge。

```powershell
$env:PLAYWRIGHT_MODULE='已有 Playwright 模块的绝对路径'
node scripts/browser-smoke.cjs
node scripts/browser-edge.cjs
```

截图和 JSON 运行报告输出到 `output/playwright/`。交付证据已复制到 `evidence/`：首页、游戏、暂停、方块选择截图以及两份运行报告。

## 已复现并修复

- Esc 在自动化环境未触发浏览器原生退出捕获：先观察失败，再增加游戏自己的暂停处理，完整操作流程通过。
- 新建世界曾重置首页选择的视距：浏览器断言先失败，再保留当前设置，异常流程验证通过。
- 首页导入错误曾隐藏在游戏 HUD 中：可见性断言先失败，再把首页通知显示到首页状态区，完整流程通过。
- 独立审查指出导入/页面隐藏保存竞态：真实队列边界复现 RED，增加世界替换期间的保存屏障和重入保护后 GREEN。
- 独立审查指出种子 `23` 的水中出生：实际生成器测试 RED，默认出生要求干燥地表后 GREEN；已存在的水中玩家位置仍可正常恢复。
- 检查脚本的异步等待曾提前结束：已根据 Playwright 实际实现改为明确等待异步布尔值，重新采样所有区块完成状态；不使用早期未加载完成的缓存数据作结论。

`scripts/build-release.py` 按允许列表生成 `releases/青岚方块-1.0.0.zip`，包括本地渲染库、源码、测试、启动器、说明和证据；不包含 node_modules、下载缓存、日志、浏览器存档或测试备份。ZIP 包内有逐文件 SHA256 清单，构建时检查压缩包完整性。
